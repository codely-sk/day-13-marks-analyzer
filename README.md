# Day 13 – Student Marks Analyzer 📊

## About the Project
The Student Marks Analyzer is a Python program that reads student marks from a CSV file and generates a performance report. It calculates totals, averages, grades, class rankings, and identifies the top-performing student.

## Features
- Read student records from a CSV file
- Calculate total and average marks
- Assign grades based on averages
- Rank students by performance
- Identify the highest-scoring student
- Create a sample CSV file automatically if one does not exist

## Concepts Used
- CSV file handling
- `csv.writer()` and `csv.DictReader()`
- Lists and dictionaries
- Functions and conditional statements
- `sum()` and `sorted()`
- `lambda` functions
- `enumerate()`
- Exception handling

## What I Learned
- How to read structured data from CSV files
- How to calculate totals and averages
- How to assign grades using conditions
- How to sort students by their performance
- How to generate a report from stored data

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run `day_13_marks_analyzer.py`.
4. Edit `student_marks.csv` to test different student marks.

## Files
- `day_13_marks_analyzer.py` — Main Python program
- `student_marks.csv` — Student names and marks
